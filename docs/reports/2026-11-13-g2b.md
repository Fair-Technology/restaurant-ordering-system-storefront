Restored on `/` and `/legal/sub-processors`. While a newly navigated shop is loading, the previous shop's name is replaced with the baseline rather than left stale.
4. Title is shop name only; nothing path/query-derived (order id / `?t=` token). Asserted on `/shops/a/orders/<id>?t=<token>`.
5. No `og:*` written from the client (asserted: 0 og meta); no static `noindex` added; no `api/` or route-rule changes.
